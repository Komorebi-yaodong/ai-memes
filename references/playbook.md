## 二、选图细则

`pick` 的 `score` 算法：标题/描述命中 ×3，其余字段命中 ×1，多词命中 +2/个，有 `story_zh` +1。它只做粗排，最终靠语义判断。

决策顺序：

1. `story_zh` 里的"适用于……""发给……"是否与用户语境一致 → 一致就选它。
2. 用户要"替我说句话" → 看 `name` 里 `『』` 的台词是否贴切。
3. 用户要"解释/科普" → 选 `type` 为 `漫画` 或 `设定图`。
4. 用户要"可爱的/好看的" → 选 `立绘`、`设定图`，别选漫画四格。

**排除项**：`type` 为 `其他`（多为设定线稿）、`anim` 动图（静态场景取首帧会失真）、无 `story_zh` 且 `name` 只是"XX娘表情包"的（信息量不足，无法判断语境）。

**注意新收录条目**：`latest N` 查出来的最新图往往 `type` 和 `story_zh` 都还空着（人工标注滞后于入库）。这类图适合"看图说话"，不适合拿来当"这句话什么梗"的答案——要梗解就换成有 `story_zh` 的老条目。

## 三、输出模板

单张：

```
![{name}]({original})

**#{id} · {category} · {type}**
台词：{从 name 提取}
用在哪：{从 story_zh 提炼一句，不照抄}
[详情页](https://aigengtu.com/zh/meme/{id})
```

多张对比（最多 3 张）：每张一行缩略图 + 一句话差异说明，让用户自己挑：

```
1. ![..](..)  #28 摸鱼失败四格 —— 适合"计划摸鱼结果加班"
2. ![..](..)  #136 摸鱼事故簿 —— 适合"自我管理失败"
```

## 四、配字（找不到合适台词时）

`https://aigengtu.com/tools/maker` 在线配字工坊：选馆藏底图 → 输入台词 → 调字体/描边/弧形排版 → 导出透明 PNG。适合"图对了但台词不对"的场景，比硬找一张贴合的图更省事。

## 六、合规红线

- **不输出**：色情、暴力、政治敏感、侮辱特定真人的图（索引里确有擦边标题，如 #006，遇到直接跳过）。
- **商用**：全部为网友二创，版权在各原作者，站点只做收录，**不代授任何商业授权**。用户提商用必须明确提示。
- **署名**：`story.contributor` 字段有贡献者署名，转述梗解时可保留。
